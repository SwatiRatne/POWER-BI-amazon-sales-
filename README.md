# POWER-BI-amazon-sales-
Power BI project analyzing Amazon Sales data (Amazon Sales Report). Includes a Power BI report (.pbix), cleaned sample data, visualization screenshots (bar charts, KPI cards, trends), methodology and reproduction steps. See README for dataset source and license.

🛒 Amazon Sales Data Analysis (Power BI Project)
📌 Project Overview
This project analyzes the Amazon Sales dataset from Kaggle (https://www.kaggle.com/datasets/zahidmughal2343/amazon-sales-2025). The goal is to explore sales performance, identify top-performing products and categories, and understand trends using measures and average calculations.

The analysis is done in Power BI and includes interactive dashboards and visualizations.

📂 Dataset
Source: Amazon Sales Dataset (Kaggle)
Data Includes:
Order ID
Product Name / Category
Sales Amount
Quantity
Profit / Revenue
Order Date
Customer / Region Details
📊 Dashboard & Visualizations
The Power BI dashboard provides insights into Amazon sales performance through different visualizations:

Sales by Category

Bar chart showing total sales across different product categories.
Highlights top-performing categories and low-performing segments.
Sales Performance Overview

KPI cards displaying key metrics such as total sales, average sales, and total quantity.
Sales Trends Over Time

Line chart showing sales trends across different time periods.
Helps identify growth patterns and seasonal variations.
Top Products Analysis

Visuals highlighting best-selling products based on sales and quantity.
Regional Sales Distribution

Map or chart showing sales performance across different regions.
Helps understand geographic contribution to overall sales.
🔑 Key Insights
Certain product categories contribute significantly more to overall sales.
Average sales metrics help identify overall performance trends.
A small number of top products drive a large portion of revenue.
Sales trends vary over time, showing patterns and possible seasonality.
Regional differences highlight variations in customer demand.
